# ADR-003: 创意工坊多源管道与自托管缓存后端 (`l4a-server`)

- **状态**: 已采纳 (Accepted)
- **背景**: 单靠 Steamworks SDK 无法拿到 `file_url` 且搜索语义差；单靠前端/本地爬取 Steam 网页易触及 429 限流；并且单机无法知道其它玩家见过的已下架条目历史或作者撤回的分包变更。
- **决策**: 建立有序回落与字段互补的 `WorkshopResolver`，新增独立可自托管的 `l4a-server`（Axum + SQLite + `/admin` 管理页），引入分级可信贡献者与防恶意标下架裁决；Web 抓取在客户端与服务端均保留显式占位 Trait。
- **后果**: 保持 v1 全部数据源优势的同时，把信息积累与社区协作从“脆弱的客户端直爬”转为“可控的混合缓存与可信上报”。
